Rush Hour Bistro is a fast canvas cooking game: order tickets land on the board with countdowns, you click ingredients (or press 1–8) to stack each dish on the plate, and serve it before its timer runs out — fast serves earn time bonuses and combos, three walk-outs close the kitchen. Plain static files, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
